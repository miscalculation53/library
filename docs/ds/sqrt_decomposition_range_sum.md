## 平方分割による一点加算・区間和クエリ $\langle O(1), O(\sqrt{N}) \rangle$

おおむね Fenwick Tree 相当の操作が、一点加算 $O(1)$ 時間、区間和 $O(\sqrt{N})$ 時間でできる。セグ木相当の操作にするのは難しい気がする？

代表的な使用例：Mo の中で使う。区間の伸縮 $O(N\sqrt{Q})$ 回を $O(1)$ 時間で、答えの計算 $O(Q)$ 回を $O(\sqrt{N})$ 時間で行う。

### コンストラクタ

```cpp
(1) SqrtDecompositionRangeSum<G, B=512>(int n)
(2) SqrtDecompositionRangeSum<G, B=512>(vc<G::S> vec)
```

初期化を行う。$B$ はブロックサイズで、$B = \Theta(\sqrt{n})$ 程度にとるのがよい。デフォルトでは $B = 512$。

$B$ について、具体的な定数倍はガチャなところがあるが、最悪ケースでの `op` 演算の回数はおおむね $n/B + 2B$ 回程度なので、これを最小化すると考えるならば $B = \sqrt{n/2}$ 程度がよさそう？ もちろんこれは与えられる区間クエリの性質によって変わって、たとえば接頭辞クエリしか来ない場合は最悪 $n/B + B$ 回になるので $B = \sqrt{n}$ がよいか。

なお、$B$ をテンプレート引数で与えているのは高速化のため。

##### 制約

- `G` は可換で、群（一部の操作はモノイドでよい）


### メンバ関数

#### get

```cpp
G::S get(int p)
```
添字 $p$ の値を返す。

##### 制約

- $0 \leq p < n$
- `G` はモノイドでよい

##### 計算量

- $O(1)$

#### add

```cpp
void add(int p, G::S x)
```

添字 $p$ の値に $x$ を加える。

##### 制約

- $0 \leq p < n$
- `G` はモノイドでよい

##### 計算量

- $O(1)$

#### set

```cpp
void set(int p, G::S x)
```

添字 $p$ の値を $x$ に更新する。

##### 制約

- $0 \leq p < n$
- `G` は群であることが必要

##### 計算量

- $O(1)$


#### sum

```cpp
G::S sum(int l, int r)
```

区間 $[l, r)$ の和を求める。

##### 制約

- $0 \leq l < r \leq n$
- `G` はモノイドでよい

##### 計算量

- $O(\sqrt{n})$
