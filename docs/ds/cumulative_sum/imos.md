## 概要

$1$ 次元 imos 法

更新と取得を混ぜ、取得した位置まで差分を順次展開する場合は [動的 imos 法](imos_dynamic.md) を使う。

## 詳細なドキュメント

#### コンストラクタ

```cpp
(1) Imos<G>()
(2) Imos<G>(int n)
(3) Imos<G>(const vc<G::S>& a)
```

- (1)：デフォルトコンストラクタ。
- (2)：単位元を $n$ 個並べた列で初期化する。
- (3)：列 `a` で初期化する。

##### 制約

- `G` は可換群
- (2)：$n \geq 0$

##### 計算量

- (2)：$O(n)$
- (3)：$O(n)$

#### add

```cpp
void add(int l, int r, const S& v)
```

区間 $[l, r)$ の各要素に $v$ を作用させる。

##### 制約

- $0 \leq l \leq r \leq n$

##### 計算量

- $O(1)$

#### content

```cpp
vc<S> content()
```

すべての区間作用を反映した長さ $n$ の列を返す。

##### 計算量

- 時間：$O(n)$
