## 概要

区間更新・点代入・点取得を扱う $1$ 次元 imos 法。配る DP などで使う。

`get(i)` と `set(i, v)` は $[0,i]$ の差分を値に展開する。以後の `add(l, r, v)` は、展開範囲より後ろの区間に行う。空区間への更新はいつでも行える。`set` による点代入は取得済みの位置にも使える。取得位置は任意の順序でよく、展開済みの値は何度でも取得できる。

差分を必要になった位置まで累積し、配列をその場で値に置き換える。長さ $n$、`content` を除く操作数 $q$ に対し、構築と全操作の時間は $O(n+q)$、空間は $O(n)$。`G` の演算は $O(1)$ とする。

点更新・区間取得には [動的累積和](cumulative_sum_dynamic.md)、$2$ 次元には [動的 imos 法 (2D)](imos_dynamic_2d.md) を使う。

## 使用例

次の $2$ 項へ配る DP。

```cpp
ImosDynamic<GroupAddSub<ll>> dp(6);
dp.set(0, 1);
for (int i = 0; i < 6; ++i)
{
  ll v = dp.get(i);
  dp.add(i + 1, min(6, i + 3), v);
}
assert(dp.get(5) == 8);
```

## 詳細なドキュメント

### ImosDynamic

#### コンストラクタ

```cpp
(1) ImosDynamic<G>()
(2) ImosDynamic<G>(int n)
(3) ImosDynamic<G>(const vc<S>& a)
```

`S = G::S`。

- (1)：長さ $0$ で初期化する。
- (2)：単位元を $n$ 個並べた列で初期化する。
- (3)：列 `a` で初期化する。各位置は未展開。

##### 制約

- `G` は可換群。
- (2)：$n\geq0$。

##### 計算量

- (1)：$O(1)$。
- (2), (3)：$O(n)$。

#### add

```cpp
void add(int l, int r, const S& v)
```

$[l,r)$ の各要素を $a_i\gets G::op(a_i,v)$ とする。

##### 制約

- $0\leq l\leq r\leq n$。
- $l<r$ の場合、区間内の全位置が未展開。これは $l$ が未展開であることと同値。

##### 計算量

- $O(1)$。

#### set

```cpp
void set(int i, const S& v)
```

位置 $i$ の現在値を $v$ に置き換える。取得済みの位置にも使え、他の位置の値は保つ。内部で `get(i)` を行うため、$[0,i]$ の差分が展開される。

##### 制約

- $0\leq i<n$。

##### 計算量

- 新たに展開する要素数を $k$ として $O(k+1)$。展開済みの位置への代入は $O(1)$。

#### get

```cpp
S get(int i)
```

$[0,i]$ の差分を値に展開し、$a_i$ を返す。

##### 制約

- $0\leq i<n$。

##### 計算量

- 新たに展開する要素数を $k$ として $O(k+1)$。全操作での $k$ の合計は高々 $n$。

#### content

```cpp
vc<S> content() const
```

すべての更新を反映した長さ $n$ の列のコピーを返す。元の展開範囲を保つため、デバッグ出力の後も同じ範囲に `add` できる。

##### 計算量

- $O(n)$。
