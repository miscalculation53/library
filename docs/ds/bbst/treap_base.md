## 概要

`SequenceTree`, `LazySequenceTree`, `OrderedMapTree`, `LazyOrderedMapTree` の共通実装。
利用時は、それぞれの公開ヘッダを読み込む。

Treap の各ノードに独立な乱数の優先度を割り当て、順位による分割と順序を保つ連結を行う。
各ノードは部分木の要素数とモノイド積を持つ。列用のノードは逆方向の積と反転フラグ、遅延更新用のノードは作用と有効フラグも持つ。
順位用の要素数は、モノイドが持つ長さなどの情報と独立して管理する。

基本操作の期待計算量は $O(\log(n+1))$。乱数と独立な操作列を前提とする。
ノード全体の空間計算量は $O(n)$、再帰処理の深さは木の高さに等しい。
以下、モノイド演算・作用・比較・値のコピーは $O(1)$ とする。

## 使用例

```cpp
#include "ds/bbst/sequence.hpp"

SequenceTree<MonoidAdd<ll>> a({1, 2, 3});
auto b = a.split(1);
a.concat(std::move(b));
assert(a.all_prod() == 6);
```

## 詳細なドキュメント

### 所有権

各通常版の木はノードを所有する。`split` / `extract` は所有権を分け、`concat` / `join` は引数の木から所有権を移す。
独立に構築した木同士も連結できる。

木の受け渡しには move を使う。内容を複製する場合は `content()` の結果から別の木を構築する。
move 後と連結の引数に使った木は空になり、再利用できる。
map の move では比較器をコピーして、移動元でも同じ順序を使えるようにする。
move 構築は $O(1)$、move 代入は代入先の古い要素数を $m$ として $O(m+1)$。
破棄と `clear()` は $O(n)$。ノードの解放に使う追加メモリは $O(1)$。

### 内部の構成

- `TreapNode`：キー・モノイド・反転・遅延作用の情報を組み合わせる。
- `TreapBase<Node>`：ノードの所有、構築、分割、連結、順位探索、区間処理を担当する。
- `pull()`：子の情報から部分木のサイズと積を再計算する。
- `push()`：反転と遅延作用を子へ伝える。

`treap_random()` は内部の優先度生成器。ライブラリ利用側の乱数生成器とは独立している。
