## 概要

最短ベクトル問題（$2$ 次元）

## 使用例

```cpp
auto [x, y] = svp2d(pair<ll, ll>{2, 0}, pair<ll, ll>{1, 1});
assert(x * x + y * y == 2);
```

## 詳細なドキュメント

#### svp2d

```cpp
pair<T, T> svp2d<T=ll, U=larger_int_t<T>>(pair<T, T> a, pair<T, T> b)
```

整数係数で $a, b$ から張られる格子のうち、ノルムの二乗が最小のベクトルのひとつを返す。

返り値はベクトルそのもの `(x, y)`。符号は一意でない。

基底を短くするときの射影係数は、最も近い整数を選び、同距離なら大きい方を選ぶ。係数とベクトルの更新は `U` で計算する。

`U=i128`、`T` が 64 bit 以下の符号付き整数型で、入力の全成分が $[-2^{30},2^{30})$ に入れば、内積・ノルム・除算を `ll` で計算する。

##### 制約

- `T` は符号付き整数型
- `U` は `T` の積とノルムの二乗を保持できる符号付き整数型
- `a`, `b` はともに非零
- 計算途中のベクトルの各成分が `T` に収まる

##### 計算量

入力ベクトルのノルムの最大値を $C$ として、

- $O(\log C)$ 回の整数演算
