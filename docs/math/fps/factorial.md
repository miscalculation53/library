## 階乗

https://suisen-kyopro.hatenablog.com/entry/2023/11/22/201600

$p$ を法（素数）とする。$n!$ を計算するクエリが $n < p$ の範囲で与えられるとき、パラメータ $B = 2^k$ をとって、前計算 $O\left(B \log B + \dfrac{p \log p}{B}\right)$ 時間、クエリ $O(B)$ 時間で計算する。$B = \sqrt{p}$ ととると前計算は $O(\sqrt{p} \log p)$ 時間となる。

本実装では、$p$ が NTT friendly の場合デフォルトで $k = 9 \ (B = 512)$、そうでない場合 $k = 11 \ (B = 2048)$ としている。これはクエリ数が $10^5$ 程度の場合を想定したものとなっている。クエリ数が少なく、単に前計算の時間を最小化したい場合は、NTT friendly の場合・そうでない場合のいずれも $k = 13 \ (B = 8192)$ 程度にとるのがよさそうか。

手法としては、$B!, (2B)!, \dots$ を前計算しておき、クエリでは最も近いところから始めて $O(B)$ 回の乗算をするというもの。前計算パートは多項式の評価点シフトを使うといい感じにできる（略、上のリンクを参照）。

### コンストラクタ

```cpp
Factorial<mint> fact(int k = -1)
```

パラメータ $k$ を与えて初期化する。デフォルトは $k = 9$。

##### 計算量

$B = 2^k$ として

- $O\left(B \log B + \dfrac{p \log p}{B}\right)$

### メンバ関数

#### factorial

```cpp
mint factorial(ll n)
```

$n!$ を `mint` 上で計算する。

##### 計算量

$B = 2^k$ として

- $O(B)$
