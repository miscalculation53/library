## 概要

単純無向グラフにおいて、相異なる $3$ 頂点 $u, v, w$ の組であって辺 $\{u, v\}, \{u, w\}, \{v, w\}$ がすべて存在するものを列挙する。このような辺の組は、（順番を入れ替えただけのものを同一視すると）たかだか $m\sqrt{2m}$ 個である。

関連する典型：長さ $n$ 総和 $m$ の非負整数列から相異なるペアを $q$ 個とったとき、その min の和は $O(m\sqrt{q})$ である。証明：

- $B$ 以上の要素の個数は $\dfrac{m}{B}$ 個以下なので、両方 $B$ 以上のペアの個数は $\dfrac{m^2}{2B^2}$ 個以下で、その総和への寄与は $\dfrac{m^2}{2B}$ 以下。
- 一方が $B$ 以下のペアは、総和への寄与が $qB$ 以下。
- $\dfrac{m^2}{2B} = qB$ つまり $B = \dfrac{m}{\sqrt{2q}}$ ととると、総和 $m\sqrt{\dfrac{q}{2}}$ 以下。

この事実を無向グラフの次数列（総和 $2m$）に対して適用することで $\displaystyle \sum_{\{u,v\} \in E} \min(\mathrm{deg}(u), \mathrm{deg}(v)) \leq m\sqrt{2m}$ がわかる。

各辺に対して次数の小さいほう（$v$ とする）の頂点の隣接頂点 $w$ をすべて調べ、辺 $\{u, w\}$ が存在するかを判定することで解ける。判定に (unordered) set あるいはソートして lower_bound を用いる方法もあるが、$u$ が固まるような順で辺を見て、配列 $\mathrm{exists}_u[w]$ を持って更新するとそれが不要になる。各辺が次数の大小に従って向きづけされていると考えてちゃんと実装すると、実装が簡潔になる上に定数倍が数分の $1$ になる。

`triangles(g)` は探索を進めながら三角形を1個ずつ返す。範囲 `for` 文で走査でき、`break` で途中終了できる。前処理と1回の走査が使うメモリは $O(n+m)$。

## 使用例

```cpp
GraphUndirected<> g(4, vc<pair<int, int>>{{0, 1}, {1, 2}, {2, 0}, {2, 3}});
for (auto [u, v, w] : triangles(g)) {
  // 三角形 {u, v, w} を処理する。
}

const auto range = triangles(g);
vc<tuple<int, int, int>> result(range.begin(), range.end());
```

## 詳細なドキュメント

#### triangles

```cpp
TriangleRange triangles(const GraphUndirected<Cost, is_erasable>& g);
```

三角形を `tuple<int, int, int>` として列挙する範囲を返す。各三角形を一度ずつ返し、三角形の列挙順と組の中の頂点順は不定。辺の重みは列挙に影響しない。辺の削除に対応するグラフでは、現在の辺を対象とする。

呼び出し時のグラフを前処理して保持する。返した範囲と取得済みのイテレータは、元のグラフを変更・破棄した後も使える。

##### 制約

- `g` は単純無向グラフ

##### 計算量

- $O(n+m)$

### TriangleRange

#### begin / end

```cpp
Iterator begin() const;
Iterator end() const;
```

`begin()` は先頭の三角形を指す入力イテレータを返す。三角形が0個なら `end()` と等しい。`*it` で現在の組を取得し、`++it` で次の三角形まで探索する。

イテレータのコピーは探索状態を共有する。再走査や入れ子の走査には、改めて `begin()` を呼ぶ。イテレータは範囲オブジェクトの破棄後も使える。`*it` の参照は、そのイテレータを進めるか破棄するまで有効。

##### 計算量

- `begin()` から終端までの走査全体：$O(n+m\sqrt{m})$（利用者側の処理を除く）
- `end()`、値の参照、イテレータのコピー・比較：$O(1)$
