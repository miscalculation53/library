## 概要

無向グラフの空でないクリークを、頂点番号の配列として1個ずつ列挙する。範囲 `for` 文で走査でき、`break` で途中終了できる。自己ループは除き、同じ端点の辺は1本として扱う。

頂点を次数の昇順に並べ、各辺を後ろの頂点へ向きづける。同次数では頂点番号の昇順を使う。各頂点から出る辺数の最大値を $B$ とすると、$B \leq \sqrt{2m}$ が成り立つ。各クリークをこの順で伸ばし、候補と追加頂点の隣接先の共通部分を次の候補にする。

探索には明示的なスタックを使う。前処理と1回の走査が使うメモリは $O(n+m)$。以下では、返すクリークの個数を $K$ とする。

## 使用例

```cpp
GraphUndirected<> g(3, vc<pair<int, int>>{{0, 1}, {1, 2}, {2, 0}});
for (const auto &vs : cliques(g)) {
  // vs は vc<ll>。この例では計7個のクリークを列挙する。
}

const auto range = cliques<int>(g);
vvc<int> result(range.begin(), range.end());
```

## 詳細なドキュメント

#### cliques

```cpp
CliqueRange<I> cliques<I = ll>(const GraphUndirected<Cost, is_erasable>& g);
```

クリークを `vc<I>` として列挙する範囲を返す。各クリークを一度ずつ返す。配列内の頂点は上記の次数順に並ぶ。辺の重みは列挙に影響しない。辺の削除に対応するグラフでは、現在の辺を対象とする。

呼び出し時のグラフを前処理して保持する。返した範囲と取得済みのイテレータは、元のグラフを変更・破棄した後も使える。

##### 制約

- `I` はすべての頂点番号を表せる整数型

##### 計算量

- $O((n+m)\log(n+m+1))$

### CliqueRange

#### begin / end

```cpp
Iterator begin() const;
Iterator end() const;
```

`begin()` は先頭のクリークを指す入力イテレータを返す。頂点数が0なら `end()` と等しい。`*it` で現在の頂点列を取得し、`++it` で次のクリークまで探索する。

イテレータのコピーは探索状態を共有する。再走査や入れ子の走査には、改めて `begin()` を呼ぶ。イテレータは範囲オブジェクトの破棄後も使える。`*it` の参照は、そのイテレータを進めるか破棄するまで有効。頂点列を保存するときはコピーする。

##### 計算量

- `begin()`、イテレータを1個進める操作：$O(B+1)$
- `end()`、値の参照、終端との比較：$O(1)$
- イテレータのコピー・終端以外との比較：$O(B+1)$
- `begin()` から終端までの走査全体：$O((B+1)(K+1))$（利用者側の処理を除く）
