## 概要

すべての部分木について集約した結果を求めたい場面で、グローバルに持ったデータ構造に対する「追加と削除」あるいは「追加とリセット」ができるときに使える。

似た場面ではマージテクが使えることもあるが、マージテクより計算量が軽く、また（ライブラリありきなら）実装が軽い。

仕組みとしては HLD を利用。下から求める。heavy child の情報をそのまま持ってきた上で、light child の情報は $1$ 個ずつ追加していく。

## 詳細なドキュメント

#### dsu_on_tree

```cpp
void dsu_on_tree(
  const RootedTree& g,
  const Add& add,
  const Reset& reset,
  const Rem& rem)
```

根付き木の各部分木に対するクエリを、小さい部分木の情報を捨て、heavy child の情報を残しながら処理する。

- `add(v)`：頂点 `v` を現在の集合に追加する。
- `reset(v)`：頂点 `v` の部分木の頂点がすべて入っている状態から、初期状態へ戻す。
- `rem(v)`：頂点 `v` の部分木の頂点がすべて入っている状態で呼ばれる。ここで答えを記録する。

`g` は `RootedTree`。

##### 制約

- `g` は構築済みの根付き木
- `add`, `reset`, `rem` の実行中に `g` を変更しない
- `reset(v)` は、現在入っている `v` の部分木全体を初期状態へ戻す

##### 計算量

頂点数を $n$ として、

- `add` の呼び出し回数：$O(n \log n)$
- `reset` の呼び出し回数：$O(n)$
- `rem` の呼び出し回数：$n$
- 再帰スタック：$O(n)$

各 callback が $O(1)$ なら、全体で $O(n \log n)$。
