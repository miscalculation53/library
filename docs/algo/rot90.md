## 概要

$2$ 次元グリッドの回転

## 使用例

```cpp
#include "algo/rot90.hpp"

vvc<int> a{{1, 2, 3}, {4, 5, 6}};
auto b = rot90(a);
assert(b == vvc<int>({{3, 6}, {2, 5}, {1, 4}}));
```

## 詳細なドキュメント

#### rot90

```cpp
VV rot90(const VV& a, U k = 1)
```

$2$ 次元配列 `a` を反時計回りに $90k$ 度回転する。

`k` は負でもよく、$4$ で割った余りだけが使われる。

##### 制約

- `a` の各行の長さは等しい
- `U` は整数型

##### 計算量

`a` の行数を $n$、列数を $m$ として

- $O(nm)$
