## 概要

比較回数が高々 $n\lceil\log_2 n\rceil$ 回の安定なマージソート。比較回数が重要なインタラクティブ問題などで使える。

長さ $n$ の補助配列を1回確保し、再帰の各段で読み出し元と書き込み先を交互に使う。

## 使用例

```cpp
vc<int> a = {3, 1, 2, 1};
merge_sort(a, less<int>{}); // {1, 1, 2, 3}
```

## 詳細なドキュメント

#### merge_sort

```cpp
template <class T, class Compare>
void merge_sort(vc<T>& v, const Compare& comp)
```

`comp` の順序で `v` を安定ソートする。同値な要素は入力順を保つ。

各区間を中央で二分し、左・右の順に再帰してからマージする。比較順序はこの二分再帰による通常のマージソートと同じ。

##### 制約

- `T` はコピー構築・コピー代入できる。
- `comp` は `T` に対する狭義弱順序を定める。

##### 計算量

- $O(n\log n)$
