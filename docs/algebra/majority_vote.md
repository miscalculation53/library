## 概要

`MajorityVote<T, L = ll>` は候補の個数 `cnt` を整数型 `L` で保持する。各区間の個数を保持できる型を選ぶ。`S(T cand = T{}, L cnt = 1)` で候補と個数を指定できる。

もとは、配列内の要素のうち、過半数を占める要素を見つけるためのアルゴリズム。アイデアとしては、相異なる $2$ 要素をペアにすることを繰り返し、残った要素のみが過半数の可能性があるというものである（この要素は必ず過半数とは限らないことに注意）。

本ライブラリでは、各区間で相異なる要素をペアにして消した後の候補と個数を管理し、セグメント木などに載せられる形にしている。任意の順序でペアを消しても、真の過半数要素が存在すれば最後の候補には必ずその要素が残る。したがって、求めた候補が実際に過半数を占めるかを別途（点取得・）区間頻度クエリで確認する使い方では正しく動作する。

ただし、候補が $3$ 種類以上ありうる場合、この演算は通常の意味では結合的でなく、厳密にはモノイドではない。相異なる $a,b,c$ に対して、$(a \mathbin{\mathrm{op}} b) \mathbin{\mathrm{op}} c$ の候補は $c$、$a \mathbin{\mathrm{op}} (b \mathbin{\mathrm{op}} c)$ の候補は $a$ になりうる。過半数が存在しない区間の候補と `cnt` は、セグメント木内での括り方に依存するため、これら自体に意味を持たせてはいけない。

「真の過半数が存在する場合に候補が一致し、存在しない場合はどの候補も同じ」とみなせば、過半数判定という目的に関しては括り方による差を無視できる。ただし、これは `S` の値だけから定まる通常の同値関係ではない。候補が高々 $2$ 種類の場合に限れば、`cnt = 0` の状態をすべて同一視することで、演算は二種類の個数差の加算と同一になり、実際にモノイドとして扱える。

## 使用例

```cpp
#include "algebra/majority_vote.hpp"

using M = MajorityVote<int>;
vc<int> a{2, 1, 2, 2, 3};
auto candidate = M::e();
for (int x : a) candidate = M::op(candidate, M::S(x));
assert(candidate.cand == 2);
bool has_majority = count(a.begin(), a.end(), candidate.cand) > int(a.size()) / 2;
assert(has_majority);
```

## 詳細なドキュメント

### MajorityVote<T, L = ll>

#### S

```cpp
S(T cand = T{}, L cnt = 1)
```

候補 `cand` と、異なる値を相殺した後の個数 `cnt` を保持する。

##### 制約

- `L` は集約する個数を表現できる整数型
- `T` はデフォルト構築と等値比較が可能

##### 計算量

- $O(1)$（要素の構築・比較を $O(1)$ とする）

#### op・e

```cpp
static S op(const S& a, const S& b)
static S e()
```

`op` は候補が同じなら個数を加算し、異なるなら個数を相殺する。`e()` は個数 $0$ の状態を返す。得られた候補の頻度を元の区間で確認して過半数を判定する。

##### 計算量

- $O(1)$（要素のコピー・比較を $O(1)$ とする）
