rank・求解は $n\times(n+31)$、rank $n-7$ の行列。
$A=L\operatorname{diag}(I_{n-7},0)U$ とし、$L,U$ は対角・隣接成分が 1 の二重対角行列。
rank は既定の 2 試行。作用回数は $A,A^\top$ の合計で、求解では計測側の解の検算 1 回も含む。

循環シフトは最小多項式が $n$ 次なので、最初の射影で結果が確定するケース。
4 ブロックのケースは不変因子が $(x^{n/4}-1)$ の 4 個となり、基底を保持する一般ケースを通る。
不変因子の実測値は次元を 2 倍にすると約 7.4 倍になっており、立方時間の影響が現れている。
作用が速くても一般ケースの基底構築は軽くならない。大規模な非巡回行列に対する省メモリ実装ではない。

## 検証

`verify/mytest/ai/bbla_extensions.test.cpp` を C++17 と C++20 で実行した。

- $\mathbf F_2$ 上の $0\le n\le3$ の全 531 行列、および $0\le n\le4$ の乱数行列 100 個。
  $xI-A$ の全小行列式の gcd から独立に求めた不変因子と比較。
- 既知の不変因子を持つ companion 行列の直和を、基底変換した 150 行列。
  nilpotent、重複固有値、複数の非線形因子を含む。追加で 28 次の例も確認。
- 特性多項式は通常経路に加え、乱数をすべて 0 にして決定的な経路も検査。
- 行数・列数 0–9 の 1,000 行列の rank と可解性を、掃き出し法と比較。
  既知の rank を持つ長方形・正方の 51 行列も検査。返す解と左核証明を直接確認。
- 失敗する射影・不変因子の試行を強制し、再試行を確認。
- modint の演算子を持たない独自の体でも、4 API を検査。
- Matrix に依存しない部分は Apple Clang の ASan / UBSan でも実行。
- `verify/yosupo/bbla_rank.test.cpp`：保存済み Library Checker の rank 36 ケースを通過。
- `verify/yosupo/bbla_characteristic_polynomial.test.cpp`：C++17 でコンパイル。
  この問題の保存済みデータはなかったため、正しさは上記の独立したテストで検証。
- 既存の `verify/mytest/ai/bbla.test.cpp` も再実行して通過。

オンライン提出は行っていない。
