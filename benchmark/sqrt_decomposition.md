# 平方分割の区間和の高速化

## 変更

- 集計用の変数を 4 本に分け、`G::op` の演算の依存を短くした。可換モノイドで利用できる。
- 長さ 32 以下の区間は、ブロック境界の計算を省いて逐次集計する。
- 末尾の短いブロックを全体として使える区間では、そのブロックの集計値を使う。
- ブロック境界は非負の `int` で計算する。一点更新は従来どおり O(1)。

汎用の `sqrt_decomposition` はコールバックを左から順に呼ぶ。
区間和には可換性を使った専用の集計ループを置いた。

## 計測

2026-09-26、macOS arm64、GCC 15.2.0、C++20、`-O2 -Wall -Wextra`。
長さ 200,003 の列に 100,000 回の操作を行う。入力生成・構築は計測外、答えの配列への書き込みは計測内。
ウォームアップ 1 回と本計測 5 回を行い、中央値を使う。新旧の実行順は交互に変え、全出力の一致を確認する。

```sh
g++-15 -std=c++20 -O2 -Wall -Wextra -I. benchmark/sqrt_decomposition.cpp -o /tmp/sqrt-bench
/tmp/sqrt-bench > benchmark/sqrt_decomposition.csv
```

[比較プログラム](sqrt_decomposition.cpp) に変更前の実装を残した。[全結果](sqrt_decomposition.csv) のうち、既定の B = 512 の結果を示す。
単位は ms、速度比は変更前 / 変更後。

| 型 | 区間・操作 | 変更前 | 変更後 | 速度比 |
| --- | --- | ---: | ---: | ---: |
| `ll` | ランダム区間 | 38.801 | 20.541 | 1.89x |
| `ll` | 接頭辞 | 24.691 | 13.746 | 1.80x |
| `ll` | 接尾辞 | 51.056 | 14.562 | 3.51x |
| `ll` | 長さ 0〜31 | 2.496 | 1.588 | 1.57x |
| `ll` | 両端がブロック境界 | 7.183 | 4.703 | 1.53x |
| `ll` | 更新 99%、区間和 1% | 0.468 | 0.412 | 1.14x |
| `modint998244353` | ランダム区間 | 63.382 | 26.830 | 2.36x |
| `modint998244353` | 接頭辞 | 49.852 | 21.117 | 2.36x |
| `modint998244353` | 接尾辞 | 86.254 | 21.459 | 4.02x |
| `modint998244353` | 長さ 0〜31 | 1.793 | 2.069 | 0.87x |
| `modint998244353` | 両端がブロック境界 | 12.537 | 6.025 | 2.08x |
| `modint998244353` | 更新 99%、区間和 1% | 1.088 | 1.096 | 0.99x |

短い区間の modint は約 15% 時間が増えた。小さいケースの差は数 ns / 操作程度で、実行環境の影響も受ける。
末尾ブロックだけの問い合わせでは、B = 512 の場合は 323 要素の走査をブロック 1 個の参照に置き換えられる。
B = 1000 の場合は末尾が 3 要素なので、短い区間として逐次集計する。

ブロック幅による O(B + n/B) のトレードオフは従来と同じ。幅の選択は区間長の分布と `G::op` のコストに合わせて調整する。

## 検証

- C++17 / C++20 で新しい 2 本のテストを実行。
- 空列、空区間、B = 1、ブロック境界、末尾の短いブロック、B > n を検査。
- 汎用関数の処理順、重複のない被覆、コピーできないコールバック、区間加算、巨大な添字の少数ブロックを検査。
- 整数、modint、独自の値型、逆元を持たない可換モノイドで、区間和を直接集計と比較。一点加算・代入を混ぜた乱数テストも実行。
- Clang の AddressSanitizer / UndefinedBehaviorSanitizer を通過。
- 保存済み Library Checker `point_add_range_sum` の 21 ケースを通過。
