# 剰余別の素数和：直接法とディリクレ指標の比較

2026-09-10、手元の macOS / x86_64、Homebrew GCC 15.2.0、C++17 `-O2 -Wall -Wextra`。
`NDEBUG` は定義していない。各測定は別プロセスで一つずつ実行し、順序は固定シードで混ぜた。
時間は篩・初期化・最終点の復元を含む関数内実時間の 3 回の中央値。プロセス起動は除く。
CPU 時間・起動を含む実時間・最大 RSS・全剰余類の答えは CSV に保存した。

## 対象と前提

すべての剰余類 $a$ について、$N$ 以下の素数の個数、または素数の総和を求める。
剰余を分類する法を $q$、答えを計算する有限体の法を $P=2013265921$ と区別する。
両方式とも同じ `static_modint32<P>` を使い、答えは $P$ で割った余り。
今回の $q$ に必要な 1 の冪根はすべてこの有限体に存在する。指標の生成時に乗法性と直交性も検証する。
複素浮動小数点の実行速度や、拡大体が必要になる場合の速度を測ったものではない。

既存の `internal::prime_prefix_sum_sieve_2_3` と同じカットオフ・合成数列挙・Fenwick Tree の処理順を使う比較用実装。
両方式に共通の篩を置き、係数表現と更新を切り替えた。公開ライブラリの API は変更していない。

- `full`: $q$ 個の剰余を直接保持。$e_a e_b=e_{ab\bmod q}$。
- `units`: $q$ と互いに素な $\varphi(q)$ 個の剰余だけを直接保持。$q$ の素因数は最後に加える。
- `characters`: 全 $\varphi(q)$ 指標を一つの篩でまとめて処理し、最後に逆変換する。
- `characters_sequential`: 各指標について同じ篩を一つずつ実行し、最終点の答えに加算する。

## 篩本体の計算量

係数の加減乗算を $O(1)$ とする。以下は法に関する前計算と最終点の復元を除いた主要項。

| 方式 | 時間 | 篩の作業空間 |
| --- | --- | --- |
| 全剰余の直接法 | $O(qN^{2/3})$ | $O(q\sqrt N)$ |
| 単元だけの直接法 | $O(\varphi(q)N^{2/3})$ | $O(\varphi(q)\sqrt N)$ |
| 全指標をまとめて処理 | $O(\varphi(q)N^{2/3})$ | $O(\varphi(q)\sqrt N)$ |
| 全指標を順番に処理 | $O(\varphi(q)N^{2/3})$ | $O(\sqrt N)$ |

この実装の法に関する表は $O(q\varphi(q))$、full の乗算先の表は $O(q^2)$ 空間。
上の作業空間とは別に必要。小さな $q$ 用の比較であり、大きな法向けの前計算は最適化していない。
指標から最終点の全剰余を復元する処理は素朴な $O(\varphi(q)^2)$。
すべての商集合の位置で剰余別の結果を保存するなら、逐次版でも出力用に $O(\varphi(q)\sqrt N)$ 空間が必要となる。
今回は最終点 $N$ の結果だけを出力する。

全指標は単元群上の関数空間の基底なので、単元だけの直接法と全指標法は同じ次元の座標変換にあたる。
[指標の直交関係（Stanford 講義ノート）](https://math.stanford.edu/~ksound/Math152A10/Dirichlet3.pdf)。

保持するすべての商集合の位置を通常の Eratosthenes の篩による結果と照合し、一致した。

## 使い分けと更新の意味

直接法では、素数での値が単項であることを利用して乗算を $O(q)$ または $O(\varphi(q))$ にする。
密な配列どうしの $O(q^2)$ 畳み込みは行わない。合成数の Fenwick Tree への追加も一成分だけ更新する。
指標法では合成数の値が各成分に現れるため、まとめる版は全指標の成分を更新する。
個数の指標値 $+1,-1$ による乗算は加減算に置き換える。総和では素数倍を含む係数を素数ごとに準備する。

すべての剰余類を求める用途では、指標への変換だけで状態数が減るわけではない。
直接法も単元に絞ると φ(q) 成分であり、しかも単項の掛け算と疎な追加を利用できる。
指標を逐次処理すれば作業メモリを減らせるが、整数除算や合成数列挙を指標ごとに繰り返す。
一括処理すればこの繰り返しを減らせる。

指標法が特に使いやすいのは、目的の関数を少数 r 個の指標で表せる場合。
そのとき篩本体は O(r N^(2/3)) となる。ただし、直接法でも乗法で閉じる少数の分類にまとめられるなら
同じ規模に圧縮できるため、少数の指標というだけで常に速いとは限らない。
一つの剰余類だけの判定関数も、一般には全指標の成分を含む。

この φ(q) 成分への圧縮は、素数そのものの剰余を数える場合の話。
σ(n) などの値を分類する問題では非単元が多数現れ得るため、同じ圧縮をそのまま使うことはできない。
